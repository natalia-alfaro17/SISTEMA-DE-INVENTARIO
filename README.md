# Sistema de Inventario

Aplicación de escritorio desarrollada en **C# Windows Forms** con conexión a **SQL Server**, diseñada para gestionar productos y controlar las existencias de un inventario.

##  Tecnologías utilizadas

- C#
- Windows Forms
- SQL Server
- Microsoft.Data.SqlClient
- Visual Studio

##  Funcionalidades

- Registro de productos.
- Consulta de productos almacenados.
- Actualización de información.
- Eliminación de productos.
- Limpieza de campos del formulario.
- Almacenamiento de información en SQL Server.

##  Base de datos

El sistema utiliza SQL Server para gestionar la información de los productos.

**Tabla: Productos**

| Campo | Descripción |
|---|---|
| Id | Identificador único |
| Nombre | Nombre del producto |
| Descripción | Detalles del producto |
| Categoría | Clasificación |
| Precio | Precio del producto |
| Stock | Cantidad disponible |

##  Operaciones CRUD

| Operación | Descripción |
|---|---|
| Create | Registrar productos |
| Read | Consultar productos |
| Update | Actualizar productos |
| Delete | Eliminar productos |

##  Objetivo del proyecto

Desarrollar una aplicación de escritorio que permita administrar productos y controlar inventarios mediante una interfaz gráfica y una base de datos relacional.



Proyecto académico desarrollado como parte de la formación en Ingeniería en Sistemas y Computación.

**Herramientas:** Visual Studio · C# · SQL Server
